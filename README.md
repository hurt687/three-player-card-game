# 三人卡牌游戏

## 第一次运行

1. 先安装 Node.js（如果电脑还没有）。
2. 在本文件夹打开终端。
3. 输入 `npm install`，等待安装完成。
4. 输入 `npm start`。
5. 浏览器打开 `http://localhost:3000`。

手机测试时，让手机和电脑连接同一个 Wi-Fi，并在手机打开电脑的局域网地址，例如 `http://192.168.1.5:3000`。

当前版本先实现“房间和三人连接”，后续再加牌和规则。

## 公网部署

项目可以部署到支持 Node.js 和 WebSocket 的云平台。部署后朋友使用云平台提供的网址即可加入，不需要连接同一个 Wi-Fi。

## 当前规则

- 普通牌按牌型和点数比较：单张、对子、三张、三张起步的顺子。
- 四张同点是“星”，A44 是“穿剑”，QQQ 是“大炮”，666 是“小炮”，特殊牌型可以越级压制普通牌型。
- 大小王出牌前必须指定为 A 到 K 的普通牌，大小王不能单独打出。
- 当前界面先支持单张出牌；服务器已经具备组合牌型判定，后续会增加多选牌操作。
- 对子、三张等相同牌型只能用同牌型比较点数；顺子按最后一张牌比较，例如 `567` 可以压 `456`，顺子不能出现 `2` 或 `3`。
- 特殊牌型压制顺序固定为：`星 ＞ 穿剑 ＞ 大炮 ＞ 小炮 ＞ 普通牌型`。
